NATIONAL PRINCESS DAY — ENIDA
================================

FILES
- index.html     Main webpage
- style.css      Styling and responsive layout
- script.js      Page transitions, sparkles, floating hearts and optional chimes
- enida.jpg      The photo supplied for Enida's final reveal

PREVIEW
1. Keep all four files in the same folder.
2. Double-click index.html to open it in a browser.
3. Internet is needed for the optional Google Fonts. The page itself works offline.

PUBLISH WITH GITHUB PAGES
1. Sign in at https://github.com and create a NEW PUBLIC repository.
   Suggested name: enida-princess-day
2. Open the repository, choose Add file > Upload files.
3. Upload index.html, style.css, script.js and enida.jpg (or upload the contents of this folder).
4. Commit the files to the main branch.
5. Go to Settings > Pages.
6. Under Build and deployment, choose Deploy from a branch.
7. Select Branch: main and Folder: /(root), then Save.
8. Wait for GitHub Pages to publish. Your site will be:
   https://YOUR-USERNAME.github.io/enida-princess-day/
9. Open that address on a phone to test it, then make a QR code pointing to that exact URL.

IMPORTANT
- Keep index.html at the repository root.
- The photo is included in this ZIP; do not rename it unless you also update the img src in index.html.
- The chime button creates gentle tones only after the visitor taps it (mobile browsers require interaction).
- Edit the letter in index.html if you want to add your own personal wording.
